◉ Mobile CCTV

OFFLINE

Ek phone Camera, dusra phone Viewer. Koi login nahi, koi install nahi. Video seedha phone se phone jaata hai.

Kaise chalega

1. Camera phone: Camera Start → Code Banao → code copy karke WhatsApp se Viewer ko bhejo.
2. Viewer phone: wo code paste karo → Jawab Code Banao → copy karke Camera wale ko bhejo.
3. Camera phone: jawab code paste karo → Connect. Live shuru!

Camera hamesha sabki jaankari me lagao. Chhupake record karna galat aur kai jagah gair-kanooni hai.
